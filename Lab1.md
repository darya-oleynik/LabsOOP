# Контрольные вопросы по ООП и классу Film

## Контрольные вопросы

### 1. Что такое класс и что такое объект?
**Класс** - это шаблон для создания объектов, он определяет поля и методы. **Объект** - это экземпляр класса, созданный по этому шаблону.

### 2. Какие существуют модификаторы доступа?
Существует 4 модификатора доступа:
- **`private`** - дает доступ к полю или методу ТОЛЬКО внутри класса, где они объявлены
- **`по умолчанию`** (package-private) - применяется, когда мы ничего не пишем. Дает доступ внутри всего пакета, но не за его пределами
- **`protected`** - дает доступ внутри пакета, а также во всех классах-наследниках
- **`public`** - доступен отовсюду, из любого места программы

### 3. Что такое инкапсуляция и зачем она нужна?
**Инкапсуляция** - принцип объектно-ориентированного программирования, который скрывает внутреннее состояние объекта от внешнего мира с возможностью доступа только через специальные методы.

**Зачем она нужна:**
- **Защита состояния** от некорректных значений - объект не позволяет установить данные, нарушающие его логику
- **Изменение внутренней реализации** без влияния на внешний вид - код не знает как данные хранятся внутри класса
- **Централизация валидации** - при изменении правил валидации не нужно искать их по всей программе и менять

### 4. Для чего нужен конструктор и чем он отличается от метода?
**Конструктор** нужен для инициализации объекта, для задания начальных значений полей. Для одного и того же объекта он вызывается только один раз. **Методы**, в свою очередь, выполняют действия над уже существующим объектом и могут вызываться сколько угодно и когда угодно.

### 5. Что делает ключевое слово `this`?
Ключевое слово `this` - это ссылка на текущий объект. Оно используется, когда параметр метода или конструктора называется так же, как и поле класса. С помощью `this` мы указываем, что обращаемся именно к полю.

### 6. Что такое классы-обертки, автоупаковка и автораспаковка?
**Классы-обертки** - специальные классы, превращающие примитивные типы в объекты. Для каждого примитивного типа есть свой класс-обертка: 
- `int` → `Integer`
- `long` → `Long`
- `double` → `Double`
- `char` → `Character`
- `boolean` → `Boolean`

Они позволяют хранить значение `null`. **Автоупаковка** - автоматическое преобразование примитива в соответствующий класс-обертку. Обратный процесс называется **автораспаковкой**.

### 7. Почему поля должны быть закрыты (`private`)?
Когда поля открыты, любой внешний код может изменить их без контроля, что приводит к ошибкам. Если мы решим переименовать поле, это приведет к переписыванию всего кода.

### 8. Какие преимущества дает ООП?
**Преимущества ООП:**
- **Моделирование предметной области** через объекты - вместо использования абстрактных функций и структур данных, мы создаем классы, соответствующие реальным сущностям
- **Повторное использование кода** через наследование и композицию - можно создать новый класс на основе уже существующего (наследование) или собрать объект из более мелких частей (композиция)
- **Управление сложностью** через инкапсуляцию - скрытие внутренней сложности объектов и оставление только того, что нужно другим частям программы
- **Гибкость** через полиморфизм - один и тот же код может работать с объектами разных классов, если они реализуют общий интерфейс или наследуются от одного родителя

## Задание. Вариант 8. Класс «Фильм»

### Требования к заданию:
- Все поля — `private`
- Для каждого поля — getter и setter с валидацией
- Метод `getDescription()`
- Создание 3 объектов в `main()`
- Ведение журнала применения ИИ

### Поля класса:
| Поле | Тип | Валидация |
|------|-----|-----------|
| `id` | `Long` | - |
| `title` | `String` | не пусто |
| `director` | `String` | не пусто |
| `year` | `int` | от 1895 до текущего |
| `rating` | `double` | от 0.0 до 10.0 |

### Формат вывода:
`«"Начало" (реж. Кристофер Нолан, 2010) — рейтинг 8.8»`

## Код программы

### Film.java
```java
public class Film {
    private Long id;
    private String title;
    private String director;
    private Integer year;
    private Double rating;

    public Film(Long id, String title, String director, Integer year, Double rating) {
        this.id = id;
        setTitle(title);
        setDirector(director);
        setYear(year);
        setRating(rating);
    }

    public String getTitle() {
        return title;
    }

    public String getDirector() {
        return director;
    }

    public Long getId() {
        return id;
    }

    public Integer getYear() {
        return year;
    }

    public Double getRating() {
        return rating;
    }

    public void setId(Long id) {
        this.id = id;
    }

    public void setTitle(String title) {
        if (title == null || title.isBlank()) {
            throw new IllegalArgumentException("Название не может быть пустым");
        }
        this.title = title;
    }

    public void setDirector(String director) {
        if (director == null || director.isBlank()) {
            throw new IllegalArgumentException("Поле 'режиссер' не может быть пустым");
        }
        this.director = director;
    }

    public void setYear(Integer year) {
        if (year < 1895 || year > java.time.Year.now().getValue()) {
            throw new IllegalArgumentException("Год должен быть от 1895 до текущего");
        }
        this.year = year;
    }

    public void setRating(Double rating) {
        if (rating < 0.0 || rating > 10.0) {
            throw new IllegalArgumentException("Рейтинг должен быть от 0.0 до 10.0");
        }
        this.rating = rating;
    }

    public String getDescription() {
        return "\"" + title + "\" (реж. " + director + ", " + year + ") — рейтинг " + rating;
    }
}
```

### Main.java
```java
public class Main {
    public static void main(String[] args) {
        Film film1 = new Film(1L, "Мстители: финал", "Энтони и Джо Руссо", 2019, 8.4);
        Film film2 = new Film(2L, "Дэдпул и Росомаха", "Шон Леви", 2024, 7.3);
        Film film3 = new Film(3L, "Одиссея", "Кристофер Нолан", 2026, 8.4);

        System.out.println("=== Список фильмов ===");
        System.out.println("1. " + film1.getDescription());
        System.out.println("2. " + film2.getDescription());
        System.out.println("3. " + film3.getDescription());
    }
}
```

## Журнал использования ИИ

### Вопрос 1: Что писать в Main в Java?
**Ответ:** Строго обязательный минимум (сигнатура метода):
```java
public static void main(String[] args) {
    // Здесь будет ваш код
}
```
Сначала сам метод должен быть объявлен именно так (иначе Java не найдет точку входа).

### Вопрос 2: Почему в классе-обертке Long указывает на ошибку в написании 1, 2 и т.д.?
**Ответ:** Ошибка возникает из-за того, что целочисленный литерал `1` по умолчанию является типом `int`, а `Long` — это класс-обертка для `long`, и прямое присвоение без суффикса `L` требует неявного преобразования, которое Java не выполняет. Для исправления необходимо использовать суффикс `L` (например, `1L`, `2L`).
